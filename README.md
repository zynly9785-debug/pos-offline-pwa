# pos-offline-pwa

POS + Inventory + Accounting (Offline-first PWA)

Tech stack: Quasar (Vue 3) + TypeScript + Pinia + PouchDB (IndexedDB) + Capacitor (APK)

Prototype scaffold: auth mock (OTP), POS offline demo, PouchDB local sync skeleton, i18n (AR/EN), Bluetooth printing placeholder.

Store sample: "محاسبي"
Currencies enabled: YER, SAR, USD

See /README-SETUP.md for local setup and running instructions.
